# Aprendizaje de Máquina

Repositorio con los laboratorios y talleres del curso de Aprendizaje de Máquina de la Maestría en Inteligencia Artificial de la Pontificia Universidad Javeriana, periodo 202630.

## Contenido

| Carpeta | Tema |
|---|---|
| `lab01` | Clasificación de texto con Naive Bayes y reporte en LaTeX |
| `lab02` | Agrupamiento con K-means |
| `lab03` | Análisis de Componentes Principales: varianza, visualización y clasificación |
| `Taller01` | Regresión lineal |
| `Taller01 - Entregable` | Versión entregada del Taller 1 con su informe |
| `Taller02` | Redes neuronales artificiales |
| `Taller03` | Agrupamiento K-Means y jerárquico aglomerativo con su informe |

## Entorno

Los notebooks se desarrollaron con Python 3.12. Para ejecutarlos localmente:

```bash
python3.12 -m venv venv_stable
source venv_stable/bin/activate
pip install -r requirements.txt
```

Los notebooks también pueden ejecutarse en Google Colab.
